# 接入

官方格式以这两页为准，本文不另造安装语法：

- Codex skills：<https://learn.chatgpt.com/docs/build-skills>
- Claude Code skills：<https://code.claude.com/docs/en/skills>
- Claude Code 插件清单：<https://code.claude.com/docs/en/plugins/manifest-reference>

仓库里已经放好的入口：

| 宿主 | 本仓库路径 |
| --- | --- |
| 共享正文 | `skills/lauren-workflow/SKILL.md` |
| Codex 仓库扫描 | `.agents/skills/lauren-workflow` |
| Claude Code 仓库扫描 | `.claude/skills/lauren-workflow` |
| 清单 | `.claude-plugin/plugin.json` |

Codex 从仓库的 `.agents/skills` 读取 Skill。Claude Code 从 `.claude/skills` 读取 Skill。清单里没有 hooks，也没有 MCP。v0.1 不把 hook 或 MCP 当作安全边界。

`lauren skills check` 只检查这些文件是否齐全、frontmatter 是否有 `name` 和 `description`。它不安装插件，也不注册 hook。Skill 只说明怎么调用 CLI。阶段、环境和发布读回的判断仍在 CLI 里。

程序从源码构建，见 [../README.md](../README.md)。需要 Go 1.22。没有已发布的二进制，也没有插件市场安装命令。运行时状态在目标项目的 `.lauren/runtime/`，问题库在 `.lauren/problems/`。更新时只替换二进制，不要用 `git reset` 覆盖这些项目数据。行为细节见 [v0.1.md](v0.1.md)。
